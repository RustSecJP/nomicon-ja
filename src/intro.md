## Unsafe Rust の黒魔術 {#the-dark-arts-of-unsafe-rust}

> この知識は「現状のまま」提供され、明示か黙示かを問わず、いかなる保証もありません。これには、あなたの精神を打ち砕き、知りえないほど果てしない宇宙へとあなたの心を漂わせる、名状しがたい恐怖を解き放つことについての保証も含まれますが、それに限りません。

The Rustonomicon は、Unsafe Rust のプログラムを書くときに理解しておかなければならない、おぞましい細部のすべてを掘り下げます。

Rust のプログラムを書きながら長く幸せな経歴を送りたいのであれば、今すぐ引き返し、この本を見たことは忘れてください。
この本は必要ありません。
しかし、unsafe なコードを書くつもりがあるなら（あるいは、単に言語のはらわたを掘り下げてみたいだけでも）、この本には役に立つ情報がたくさん載っています。

*[The Rust Programming Language][trpl]* とは違い、この本ではかなりの予備知識を前提にします。
特に、基本的なシステムプログラミングと Rust には慣れている必要があります。
これらの話題に自信がなければ、先に [The Book][trpl] を読むことを検討してください。
とはいえ、それを読んでいることは前提にしませんし、必要に応じて、ときどき基本をおさらいするようにします。
望むなら、いきなりこの本から読み始めてもかまいません。ただ、すべてを一から説明するわけではないことだけは知っておいてください。

この本は主に、[The Reference][ref] と対になる、より高い視点からの手引きとして存在します。
The Reference が言語のあらゆる部分の構文と意味論を詳しく述べるためにあるのに対し、The Rustonomicon は、それらの部品をどう組み合わせて使うのか、そしてそのときにどんな問題にぶつかるのかを説明するためにあります。

The Reference は、参照、デストラクタ、巻き戻し（unwinding）の構文と意味論を教えてくれます。しかし、それらを組み合わせると例外安全性の問題がどのように生じるのか、その問題にどう対処すればよいのかは教えてくれません。

なお、The Rustonomicon と The Reference はあまりうまく同期できていないので、内容が重複していることがあります。
一般に、2 つの文書が食い違っている場合は、The Reference のほうが正しいと考えてください（The Reference もまだ規範的な文書とは見なされておらず、単によりよく保守されているというだけです）。

この本が扱う範囲に入る話題は、次のとおりです。安全であること・安全でないことの意味、言語と標準ライブラリが提供する unsafe なプリミティブ、それらの unsafe なプリミティブを使って安全な抽象を作るための技法、部分型付けと変性、例外安全性（パニック安全性・巻き戻し安全性）、未初期化メモリの扱い、型のパニング（type punning）、並行性、ほかの言語との相互運用（FFI）、最適化の小技、言語の構成要素がコンパイラ・OS・ハードウェアのプリミティブへどう落とし込まれるか、メモリモデルに携わる人たちを**怒らせない**方法、あなたがメモリモデルに携わる人たちをどのように**怒らせることになる**のか、などです。

The Rustonomicon は、標準ライブラリのあらゆる API の意味論と保証を網羅的に説明する場所ではありません。Rust のあらゆる機能を網羅的に説明する場所でもありません。

特に断りがない限り、この本の Rust コードは Rust 2024 エディションを使います。
